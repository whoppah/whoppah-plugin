# Security

Found a vulnerability in this plugin, in the Whoppah MCP server at `mcp.whoppah.com`, or anywhere else at Whoppah? Please tell us privately:

- **Email:** privacy@whoppah.com, with the steps to reproduce.
- **GitHub:** [report a vulnerability](https://github.com/whoppah/whoppah-plugin/security/advisories/new) on this repository.

Please only use your own accounts and data, and give us time to fix the issue before you share it. We answer in English or Dutch.

Our security contact for all of Whoppah is also published at https://www.whoppah.com/.well-known/security.txt.

## What this repository contains

The plugin is configuration only: a manifest, the address of the hosted MCP server and a skill. It holds no code, keys or customer data. Every change to `main` needs a review from a Whoppah code owner.
